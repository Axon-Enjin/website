# OG image mockups

Three standalone image concepts using the user-approved geometric identity, black/cobalt palette and nerve imagery. Generated with the image-generation tool from the selected identity board and hero-art references.

1. **People, connected.** Mirrors the homepage's large sans/italic headline and branching nerve artwork.
2. **Brand first.** Prioritizes the logo and company name for recognition in small sharing previews.
3. **The connection.** Uses the documented company tagline, “The one who connects,” with fibres converging into a single signal.

The user selected option 3. Its final export is `assets/og-axon-enjin-v1.jpg`, 1200x630, with homepage Open Graph and Twitter large-image metadata pointing to the versioned production URL. `index.html` keeps all original mocks and thumbnail previews for reference.
