# Background mock choices

Three image-only alternatives requested after the full-page grid and arcs proved too busy. The same delivery section is used for direct comparison. These mocks do not change the landing page implementation.

1. **Coordinate edges:** straight construction lines and small dots confined to the outer margins. Recommended for the quieter product and company sections.
2. **Single signal:** one thin, shallow nerve path and three small nodes in the empty gap above the illustrations. More explicitly connects the delivery stages.
3. **Orbital frame:** two very large partial arcs at the outer corners, leaving the central content clear. Closest to the hero's spatial language.

Generated with the image generation tool using `texture-study/before/how-we-work.png` as the UI reference. These are design references, not HTML screenshots of new implementations. The selected direction should be reconstructed with lightweight native SVG/CSS after the user chooses.
