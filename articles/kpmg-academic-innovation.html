Cut until it runs

KPMG Philippines Academic Innovation Challenge · 1st place · Agentic Systems

Constraint. A judged clock. You cannot ship a whole operating system in a weekend. If you try, the demo dies in the first five minutes.

Decision. We picked one job: agents that do a narrow task well enough to show. Not a slogan. Not a second product name. One path a judge can walk without a tour guide.

Artifact. A working demo on that track. Externally judged. First place. That is a real signal — of build skill under time pressure.

Lesson. A win like this does not prove we can run software for a client for a year. We do not pretend it does. It proves we can choose, cut, and finish when the clock is real.
