# Axon Enjin motion preview

Run from the repository root:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173/preview/ . The original homepage is separate.

Scroll to morph the branch network into the product view, or use Play the transition. Try the product tabs, module selector, keyboard arrows, reduced-motion toggle and local inquiry preview. The form does not send a message.

The preview uses the existing dark palette, Anton and Garet, Solar icons through Iconify, and vanilla JavaScript/CSS. Fonts and icons require access to their existing CDN providers. Content follows the website grounding pack. Illustrative product data is not customer evidence.

`verify.html` runs browser interaction checks for replay progression and final state, workflows, keyboard navigation, repeated module changes, safe Accounting scope, reduced motion, local form behavior and desktop/mobile overflow. Its requestAnimationFrame timer adapter lets Chrome's virtual-time mode exercise the timeline deterministically; these checks do not measure animation smoothness or frame rate on actual devices.

Desktop was visually inspected. The 390px layout was checked in a real browser iframe. Impeccable's final detector returned no findings after increasing small text, correcting button contrast and fixing heading order. No findings were suppressed.
